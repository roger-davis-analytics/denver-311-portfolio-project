# Denver 311 Analytics Project

A production‑style Excel analytics project built using the Denver 311 public service request dataset.  
This workbook demonstrates a clean modeling architecture, semantic naming, dynamic dashboards, and professional documentation practices.

---

## 📊 Project Overview

This project analyzes Denver 311 service request data and presents a dynamic, interactive dashboard built entirely in Excel.  
The goal is to show how a well‑architected workbook can deliver clarity, speed, and analytical depth without relying on macros or external tools.

The workbook includes:

- A curated and cleaned dataset (`Slice_311`)
- A semantic naming layer for transparent logic
- A dynamic dashboard (`Visuals`) driven entirely by named formulas
- A full documentation layer inside the workbook
- A clean, maintainable sheet structure with intentional tab colors

## 🧱 Workbook Architecture

The project follows a layered, production‑style structure:

| Layer | Sheet | Purpose |
|-------|--------|---------|
| **User Guide** | `README` | Instructions for navigating and using the workbook |
| **Documentation** | `Documentation` | Methodology, QA notes, data dictionary, architecture summary |
| **Curated Data** | `Slice_311` | Cleaned and filtered dataset used by the dashboard |
| **Dashboard** | `Visuals` | Dynamic charts and KPIs driven by semantic names |
| **Semantic Layer** | `LOOKUPS` | Mapping tables and named logic supporting the dashboard |

This separation keeps the model clean, predictable, and easy to maintain.

## 🧠 Key Skills Demonstrated

- **Semantic naming architecture**  
  Clean, readable names that eliminate cell‑based formulas on the dashboard.

- **Dynamic arrays & modern Excel engine**  
  Efficient, spill‑based logic with no helper columns or legacy formulas.

- **Data cleaning & transformation**  
  Curated dataset built from a larger operational table.

- **Dashboard design**  
  Dynamic charts, slicer‑driven metrics, and a clean visual layout.

- **Documentation discipline**  
  Internal README sheet, QA notes, and a clear modeling narrative.

- **Professional workbook structure**  
  Intentional tab order, color coding, and zero stray formulas or ghost names.

## 🧭 How to Use the Workbook

1. Open the Excel file.  
2. Start on the `README` sheet for orientation.  
3. Explore the dashboard on the `Visuals` sheet.  
4. Use slicers to filter by agency, status, and date window.  
5. Review the `Documentation` sheet for methodology and QA notes.
